### <a name="_qmphm5d6rvi3"></a>**Решение**
[Диаграмма Use cases](./ДиаграммаUseCases.puml)

Текущая схема отражает требования к MVP, использует существующие компоненты системы с минимальными доработками.
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Реализация системы на основе микросервисной архитектуры с заменой функционала бек-офиса отдельным сервисом.
Перенос функций части функций АБС в отдельные микросервисы с целью возможности масштабирования под нагрузкой.

**Недостатки, ограничения, риски**

Узкое место решения: ручная обработка заявок менеджером бек-офиса.
Без перестройки архитектуры есть риск отказа систем (прежде всего интернет-банка, АБС) под нагрузкой из-за ограниченной возможности масштабирования.
Устаревшие технологии реализации интернет-банка и АБС создаёт риски для поддержки со стороны программистов.
